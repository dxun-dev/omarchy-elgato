03 / LET’S GET CONNECTED

A new home for your gear.

Start with Omarchy Quattro, Omarchy Shell, and the omarchy plugin commands. Then install and enable:

omarchy plugin add https://github.com/dxun-dev/omarchy-elgato.git --enable

Choose where to place the widget. On first enable, accept the setup prompt for any missing packages and USB access, then open the Elgato icon to configure your devices.
